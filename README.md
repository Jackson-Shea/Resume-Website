# Jackson Shea Resume Website

A responsive, single-page resume website designed and developed by Jackson Shea, showcasing work experience, education, and personal projects. Originally built and styled on [Glitch](https://glitch.com), the project has been migrated to [GitHub Pages](https://pages.github.com/) for version control and long-term hosting.

---

## Features

- Responsive layout using **HTML5** and **CSS3**
- Sticky top navigation bar with anchor links
- Downloadable PDF resume
- Font Awesome icons for contact info
- Project section featuring real-world development work
- Gradient background and media styling
- Clean typography using **Google Fonts** (`Poppins`, `Roboto`)

---

## Technologies Used

- HTML5 / CSS3
- Google Fonts
- Font Awesome
- Git & GitHub Pages
- Glitch (initial development)

## How I Built This

### On Glitch

- Developed the initial layout and content on [Glitch](https://glitch.com), including:
  - Semantic HTML structure
  - External CSS styles with custom colors, spacing, and font styling
  - Embedded Font Awesome and Google Fonts
  - Live preview for fast iteration and debugging

### Migrated to GitHub

1. **Downloaded project files from Glitch**
2. **Created a new GitHub repository**
3. **Uploaded all files**, including:
   - `index.html`
   - `styles.css`
   - `assets/` folder (containing images and resume PDF)
4. **Enabled GitHub Pages** from the repository settings
